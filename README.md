# Moss
*A minimalist social website for sharing haiku.*

![Screenshot](/src/main/resources/static/images/moss-screenshot.png)

## About

This project is a work in progress.

I'm building it as a slower, quieter corner of the internet - something simple and calm. 
A place where people can share short poems with each other without noise, clutter, or antagonism.

## Stack

- Java + Spring Boot
- PostgreSQL
- Thymeleaf
- HTML & CSS
- JavaScript

## Status

The project is still in early stages, and will get a lot more fleshed out.
